# AutoSale UA — Mini App v1

Первый технический каркас Mini App на основе утверждённого главного экрана.

## Что уже есть

- Главный экран AutoSale UA.
- 5 основных разделов.
- Telegram WebApp initialization.
- Адаптация под мобильный экран.
- Отдельные маршруты для:
  - Купити авто — лента продажи.
  - Орендувати авто — лента аренды.
  - Продати авто — бот размещения.
  - Здати авто в оренду — бот размещения.
  - Страхування авто — бот страхования.

## Следующий этап

В `app.js` заменить `null` в `ROUTES` на реальные Telegram-ссылки.

После этого по одному подключаем:
1. ленту продажи;
2. ленту аренды;
3. бота продажи;
4. бота аренды;
5. бота страхования.

Далее добавляем передачу ID опубликованного объявления из бота обратно в Mini App,
чтобы после публикации пользователь сразу попадал на своё объявление.
