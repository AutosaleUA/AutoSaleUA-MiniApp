# AutoSale UA — Mini App (Step 3)

## Що зроблено на цьому кроці

**Головна сторінка (index.html)** — той самий затверджений дизайн, але кнопки тепер
дійсно працюють:
- 🚘 «Купити авто» → відкриває каталог (catalog.html) з оголошеннями на продаж
- 🔑 «Орендувати авто» → той самий каталог, відфільтрований на оренду
- 🚗 «Продати авто» → відкриває наявного робочого бота @AutoSaleUkraine_bot
- 🔑 «Здати в оренду» та 🛡️ «Страхування» → показують акуратне повідомлення
  «розділ у розробці» (боти для цих розділів ще не створені)

**Каталог (catalog.html)** — список оголошень + фільтри (марка, місто, сортування)
+ картка авто з повним описом і кнопкою «Написати продавцю» (відкриває Telegram
чат із продавцем). Поля картки (місто, марка, модель, рік, пробіг, коробка,
паливо, ціна, контакт, опис) повторюють формат, яким бот уже публікує
оголошення в канал @AutoSaleUA_Cars.

## Важливо: зараз оголошення — демонстраційні (data.js)

Каталог поки читає масив CAR_LISTINGS з файлу `data.js` — це тестові дані
у тому ж форматі, що й реальні пости бота. Це зроблено навмисно: спочатку
узгодити вигляд і поведінку інтерфейсу, а потім підключити справжнє джерело
даних без переробки решти коду.

## Що потрібно для реальних оголошень (наступний крок)

Щоб оголошення, подані через бота, автоматично зʼявлялися в каталозі
мініапки, потрібне одне з двох:

1. **Бот пише оголошення в базу даних** (наприклад, Google Sheets, Supabase,
   Firebase або власна БД на сервері бота), а каталог мініапки робить
   `fetch()` до цієї бази замість `data.js`. Це найнадійніший варіант.
2. Мініапка читає пости прямо з каналу через Telegram Bot API — складніше
   в підтримці й менш гнучко для фільтрів/сортування.

Для варіанту 1 знадобиться доступ до коду бота (або хоча б до бази, яку він
використовує) — саме про це запитувалось раніше в чаті.

## Розділи, які ще не створені

- Бот «Здати авто в оренду» (за аналогією з ботом продажу)
- Бот «Страхування» з автоматичним розрахунком ціни — тут окремо знадобиться
  джерело тарифів (API страхової компанії або власна формула розрахунку)
